Ranking / Metodología

Cómo se construye el ranking de GitHub en Perú

Este proyecto ayuda a explorar perfiles de GitHub vinculados a Perú mediante su ubicación declarada. Es una iniciativa de la comunidad y no está afiliada con GitHub.

Fuente y actualización

La acción de código abierto top-github-users-action de Gayan Kuruppu consulta GitHub y guarda una caché en el repositorio. La web se genera a partir de esa caché; no consulta la API de GitHub cuando navegas.

El workflow tiene una actualización diaria programada, pero puede fallar o conservar datos anteriores. La fecha mostrada en el ranking es la del último commit del archivo de caché, expresada en hora de Perú; no garantiza que todos los perfiles se hayan consultado a esa hora.

Criterios de inclusión

La búsqueda utiliza “Peru” y las ciudades definidas en la configuración pública. El umbral actual es de 5 seguidores. La caché puede contener personas y organizaciones, y no representa a todas las personas que programan en Perú.

Las ubicaciones son texto escrito por cada perfil: no verificamos residencia, identidad ni nacionalidad. Un texto puede mencionar varios lugares o contener información imprecisa. Los filtros de ciudad reconocen nombres completos sin distinguir mayúsculas ni tildes; no realizan geocodificación.

Qué significa cada métrica

  • Públicas: contribuciones públicas reportadas por la consulta del generador.
  • Totales: suma de contribuciones públicas y privadas reportadas. No se exponen detalles de repositorios privados.
  • Seguidores: número de seguidores del perfil en la última información almacenada.

La consulta del generador utiliza contributionsCollection sin indicar fechas explícitas: se aplica el periodo predeterminado de GitHub. Las cifras no se presentan como un histórico completo de la cuenta. El ranking mide estas cifras, no la calidad del código ni la capacidad profesional.

Las posiciones se calculan sobre todos los perfiles incluidos, de mayor a menor por la métrica elegida. Los empates comparten posición y dejan un salto posterior (1, 1, 3). Filtrar no cambia la posición nacional. Los seguidores acumulados suman las cuentas de cada perfil y no son personas únicas.

Navegación y descarga

Las páginas estáticas muestran bloques de 25 perfiles, con enlaces para recorrer todo el ranking sin JavaScript. Con JavaScript puedes usar scroll infinito, filtros y búsqueda. La descarga CSV incluye todos los resultados filtrados, aunque todavía no se hayan mostrado en el feed.

El archivo fuente está disponible en la caché pública. La web también ofrece una selección de campos en JSON.

El fondo decorativo es una imagen generada con IA y no aporta evidencia sobre los perfiles.
